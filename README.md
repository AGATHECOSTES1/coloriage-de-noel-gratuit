# Coloriage de Noël gratuit

Site statique gratuit, prêt à publier avec GitHub Pages.

## Contenu
- index.html
- 20 coloriages PNG A4 (200 dpi) : 10 Noël + 10 poneys
- boutons Télécharger et Voir / imprimer

## Mise en ligne avec GitHub Pages
1. Créer un dépôt public sur GitHub.
2. Envoyer tous les fichiers et dossiers de ce projet.
3. Dans Settings > Pages, choisir la branche `main` et le dossier `/ (root)`.
4. Enregistrer : GitHub publiera le site.

Le site est entièrement statique : aucune base de données ni hébergement serveur n'est nécessaire.
